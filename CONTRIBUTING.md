# Contributing

Open an issue before a substantial change. Keep changes focused on an existing free component, accessibility, documentation or a reproducible bug.

1. Run `npm ci`.
2. Make the change and update its example and documentation.
3. Run `npm run check`.
4. Open a pull request describing the behavior and verification.

Preserve keyboard access, reduced-motion behavior and existing component APIs. Use media that you own or can redistribute and include its license. Do not add website layouts, brand assets, customer information, credentials or premium source. Contributors retain copyright to their work. By submitting a contribution, you agree to license it under the repository’s PolyForm Perimeter 1.0.0 license. Do not contribute code you cannot license on those terms.
