# License decision

The recommended standard license is PolyForm Perimeter 1.0.0. It permits use, modification and distribution for permitted purposes, and excludes providing a product that competes with the licensed software. This is a source-available license. Its competition restriction does not meet the Open Source Initiative definition.

This fits the intended use in personal websites, commercial websites and ordinary client projects, while restricting a competing component library built from this source. The restriction can affect other products offering substitute functionality. Its application depends on the product and jurisdiction. It does not prohibit every resale of every product containing a component.

Standard open-source licenses such as MIT and Apache-2.0 permit commercial redistribution and resale. Selecting either would accept that tradeoff. A stronger custom restriction would need a separately reviewed commercial license.

The owner approved PolyForm Perimeter 1.0.0 and public GitHub publication on 2026-11-27. The standard license text is applied in LICENSE with the required notice “Copyright 2026 Pixsel.dev contributors.” npm package publication remains disabled. Third-party dependency licenses continue to apply.

- [Official PolyForm Perimeter text](https://github.com/polyformproject/polyform-licenses/blob/1.0.0/PolyForm-Perimeter-1.0.0.md)
- [PolyForm license comparison](https://polyformproject.org/licenses)
- [Open Source Definition](https://opensource.org/osd)

Premium products retain their separate proprietary licensing. Publishing the free components does not license the platform or premium repositories.
